A small number of Swedish-format tournaments, mostly in Europe, allow only core set reprints in Unlimited and the ultra-rare "Summer" printing. In almost every other OS setting, you'll find a permissive reprint policy that allows any card printing with the same art and frame design. These affordable "isomorphic" reprints can be found in Revised, Chronicles, and even foreign-language printings. If a card in this book is shown with a ↻ symbol, find its entry in the Index (p. [X](#index))—the codes listed there indicate which sets to plunder.
